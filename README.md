# YouTube Timestamped Bookmarks

Bookmarks the current YouTube video with a timestamp. This extension allows you to effortlessly save your spot in any YouTube video with a single click or keyboard shortcut, and easily manage those bookmarks right from your browser toolbar.

## Installation

Download the extension directly from Firefox Add-ons:
[YouTube Timestamped Bookmarks on Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/youtube-timestamped-bookmark/)

## Features & Configuration

* **Precise Timestamping:** Automatically captures the exact current time of the video and appends it to the bookmark URL.
* **Quick Bookmark Shortcut:** Use `Alt+Shift+X` to instantly bookmark the video you are currently watching.
* **Smart Overwrite:** Automatically replaces existing timestamp bookmarks for the same video to prevent duplicates.
* **Customizable Titles:** Use patterns (like `{title} [{time}]`) and optionally truncate long video titles by word or character count.
* **Action Mode:** Configure the extension icon to act as a one-click instant bookmark button instead of opening the options menu.
* **Double-Click to Delete:** When using Action Mode, you can enable a feature to delete the current video's bookmark by double-clicking the extension icon. You can even customize the millisecond delay required for the double-click.

## Usage 

1. Navigate to any YouTube video.
2. Press `Alt+Shift+X` to quickly save your spot.
3. Alternatively, click the extension icon to open the options menu. 
4. **Instant Bookmarking:** Set the icon to **Action Mode** in the settings to bookmark instantly on a single click.
5. **Quick Deletion:** If Action Mode is active and double-click is enabled, simply double-click the extension icon to safely remove the bookmark for that video.
6. Access the extension's options to tweak title formats, truncations, double-click speeds, and hotkey behavior.
